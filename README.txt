Quickly and easily add a rental yield calculator to your website

== Description ==

Add a free, easy-to-use rental yield calculator to your WordPress website in seconds. Help landlords, property investors and prospective buyers instantly calculate the potential rental yield of an investment property.

The **Property Hive Rental Yield Calculator** plugin makes it simple to add an interactive rental yield calculator to any WordPress website. Perfect for estate agents, letting agents, landlords and property professionals looking to help visitors assess the potential returns on a buy-to-let or investment property.

Simply add a shortcode to any page or post, and visitors can instantly calculate the rental yield based on the property purchase price and monthly rental income.

= Features =

* **Free WordPress rental yield calculator** - No subscription or ongoing fees.
* **Instant rental yield calculations** - Calculate the potential annual rental yield of a property in seconds.
* **Simple property investment calculations** - Visitors enter the purchase price and monthly rent to calculate rental yield.
* **Ideal for buy-to-let properties** - Help landlords and property investors assess potential rental returns.
* **Easy shortcode integration** - Add a rental yield calculator to any WordPress page or post in seconds.
* **Simple to use** - No complicated configuration or technical knowledge required.
* **Works independently** - Compatible with any WordPress website. Property Hive is not required.

= How Does the Rental Yield Calculator Work? =

The calculator allows visitors to estimate the gross rental yield of a property using two simple figures:

1. **Property purchase price** - The price paid or expected to be paid for the property.
2. **Monthly rental income** - The amount of rent the property generates or is expected to generate each month.

Using these figures, the calculator instantly calculates the annual gross rental yield as a percentage of the property purchase price.

For example, a property purchased for £200,000 generating £1,000 per month in rent would have an annual gross rental yield of 6%.

This makes it easy for landlords and property investors to compare potential rental returns across different properties.

= How to Add a Rental Yield Calculator to WordPress =

Getting started couldn't be easier:

1. Install and activate the Property Hive Rental Yield Calculator plugin.
2. Create or edit the WordPress page or post where you want the calculator to appear.
3. Add the following shortcode:

`[rental_yield_calculator]`

4. Save your page and you're done! Visitors can now calculate rental yields directly on your website.

== Installation ==

= Automatic installation =

Automatic installation is the easiest option as WordPress handles the file transfers itself and you don’t need to leave your web browser. To do an automatic install of the Property Hive Rental Yield Calculator, log in to your WordPress dashboard, navigate to the Plugins menu and click Add New.

In the search field type “Property Hive Rental Yield Calculator” and click Search Plugins. Once you’ve found our plugin you can view details about it such as the point release, rating and description. Most importantly of course, you can install it by simply clicking “Install Now”.

= Manual installation =

The manual installation method involves downloading the plugin and uploading it to your webserver via your favourite FTP application. The WordPress codex contains [instructions on how to do this here](https://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation).

= Updating =

Updating should work like a charm; as always though, ensure you backup your site just in case.
